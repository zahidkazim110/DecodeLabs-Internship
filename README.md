# 🤖 SmartBot AI Assistant

## DecodeLabs Artificial Intelligence Internship - Project 1

### 📌 Overview

SmartBot AI Assistant is a Rule-Based AI Chatbot developed using Python and Tkinter. The chatbot responds to predefined user inputs, performs simple calculations, provides date and time information, and interacts with users through a professional graphical user interface.

This project demonstrates the fundamentals of Artificial Intelligence using decision-making logic, control flow, and user interaction.

---

## 🚀 Features

- Interactive GUI using Tkinter
- Rule-Based AI Responses
- Date & Time Support
- Simple Calculator
- Addition, Subtraction, Multiplication, Division
- Motivational Quotes
- AI & Python Knowledge Responses
- Friendly Conversation Support
- Professional Chat Interface

---

- Python
- Tkinter
- Datetime Module
